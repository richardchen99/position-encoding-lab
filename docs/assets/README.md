# Documentation figures

All screenshots are captures of the running [Position Encoding Lab](https://richardchen99.github.io/position-encoding-lab/) using public built-in examples. They show application content only and are also used in the [project research note](https://richardchen99.github.io/blog/position-encoding-lab-note/). Capture date: **2026-09-18**.

| File | Captured state |
| --- | --- |
| [`overview.jpg`](overview.jpg) | RoPE geometry and the shared attention workbench |
| [`shift.jpg`](shift.jpg) | Short example; Query 5, Key 1; shared position shift 24; zero displayed score error |
| [`comparison.jpg`](comparison.jpg) | Long example; Query 11, Key 2; shift 0; three attention distributions |

[`architecture.svg`](architecture.svg) is an original, editable vector schematic prepared for this repository. [`architecture.png`](architecture.png) is its 3,200-pixel-wide raster export. It shows shared inputs, the three position mechanisms, and numerical observations; see the [README](../../README.md#mathematical-scope) for assumptions.

No screenshot is a synthetic interface image. The framework diagram is drawn with vector shapes and text, not generated by a text-to-image model. Figures contain no editor windows, browser chrome, local paths, or private account details. Numerical values illustrate the stated experiment and are not performance benchmarks.
